# עוף טוב — סיכום קמפיין נאגטס

מצגת סיכום אינטראקטיבית (HTML) לקמפיין השקת הנאגטס של עוף טוב, יולי–ספטמבר 2026.
הוכנה על ידי 42creative.

## מבנה
- `index.html` — המצגת עצמה (14 שקופיות, RTL, scroll-snap)
- `assets.js` — כל התמונות כ-base64 (נוצר אוטומטית מקובץ ה-PDF המקורי)

## עריכה
כל התוכן והנתונים נמצאים ב-`index.html`. התמונות מוזרקות לפי `data-a="<key>"` מתוך האובייקט `A` ב-`assets.js`.

## ניווט במצגת
גלילה, חיצים במקלדת, או הנקודות בצד שמאל.
